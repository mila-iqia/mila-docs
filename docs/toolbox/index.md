# Toolbox

This section lists tools that help with research on the clusters, grouped by
the stage of the project they support.

!!! tip "Start from a template"
    The [Research Project Template](https://mila-iqia.github.io/ResearchTemplate/)
    provides a ready-to-use project structure built on
    [Hydra](https://hydra.cc/),
    [PyTorch Lightning](https://lightning.ai/docs/pytorch/stable/),
    [JAX](https://docs.jax.dev/en/latest/), [WandB](https://wandb.ai/), and
    [pytest](https://docs.pytest.org/en/stable/).
